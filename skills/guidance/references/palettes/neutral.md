# Palette table: neutral

Quiet, near-greyscale with a hint of the brand hue. Serious tools, dense data, editorial.

Generated by tools/build_tables.py from the Material 3 colour system (role tones from material-color-utilities spec 2021; tone = CIE L*, hue and chroma in OKLCH). Every row passes all 120 WCAG role-pair checks in light and dark.

How to use: compute the brand colour's HSL hue (see `../data/colour.md`), round to the nearest multiple of 5 (360 becomes 0), and read the single line that starts with `h<hue>` (three digits, e.g. `h035`). Use `grey` when the brand has HSL saturation under 12% or is black, white or grey. Copy values exactly; never edit hex codes by hand.

Row format: `h<hue> | light: role=#hex ... | dark: role=#hex ...`
